半熟英雄4 (SLPM-65839) 资源分析结果
====================================

光盘
- 文件: 半熟英雄4-7人的半熟英雄.iso
- 类型: PS2 DVD (Mode1 / 2048 字节扇区)
- 体积: 约 1.78 GiB（933104 扇区）

ISO9660/UDF 目录里只有启动文件（约 4MB）
- SYSTEM.CNF / SLPM_658.39 / IOP 模块
- 游戏资源在无名扇区，由 ELF 内 19967 槽哈希表索引

VFS 哈希表（ELF VA 0x432C48，12 字节/槽）
- field0 = LBA
- field2 = 打包后字节大小
- field3 = 解压后大小（0 = 未压缩）
- 约 9512 个唯一 (LBA, size)；其中 43 个是 mes 文案包
- 其它常见头：VSF\0 音频、EGG\0 角色、SeBl、MPEG 00 00 01 ba、F7(19 = 0x19283746 压缩包
- ELF 里的 Encryption/CRC-Error 字符串属于 FMV 宏块，不是 mes 打包

压缩（EE 0x22bc28）
- 8 字节头：u32 packed_size, u32 unpacked_size
- 随后 LZSS：flag 字节 LSB=1 为字面量，0 为 2 字节匹配
  offset = b0 | ((b1 & 0xF0)<<4)，length = (b1 & 0xF)+3，窗口 4096 / 起点 0xFEE
- TIM2 / sprte 文件都是这层包装（type 字节 0x7f=TIM2, 0xdf=sprte）
- 实现：tools/lzss.py

文案文件格式（.mes）
- 文件头 u32 = 字节 trie 根偏移
- 正文：NUL 结尾字符串 + 以 ASCII key 为路径的字节 trie
- key 明文：sysmes_ / menu_ / f_sun_ / ev_ / eg_ / d_ 等
- 字形字节：(byte * 189) mod 256 还原；1 字节假名 0–89 / 片假名 +90
- 2 字节码若 < 字库 bank1 数量则 +192 得到字形号
- 引擎接口：LoadMes / OpenMes / PrintMes / GetMesLine（按行 strlen 切开）

KIWI 字库
- 运行时 6 套（RAM 里 magic "KIWI" version 17）
  16x16 4bpp  192+1727  主字库（对话/菜单，idx0；汉化灌 n1=2760）
  16x16 4bpp  192+837   中等（idx1，对话气泡也走这套；汉化灌 n1=2760，与 idx0 同一份）
  16x16 4bpp  192+349   子集 idx5（字形号正好覆盖 mes 用到的 192–540；仍日文）
  12x12 4bpp  192+123/124  小字（idx2/3；汉化灌 n1=2760）
  16x16 8bpp  90        彩色/特殊
- 头 64 字节：+8/+10 宽高，+12 色深相关，+32/+34 两档字形数
  +64 调色板，+68/+72 两档 4bpp 点阵，+76/+80 每字 2 字节度量
- 1 字节码 0–191 = bank0（假名已核对：0=あ … 90=ア）
- 2 字节码 +192 = bank1
- 图集 PNG：extracted/font/kiwi_atlas/
- 工具：tools/kiwi_font.py（从 eeMemory.bin 导出图集；build_kiwi_font.py 也用它的头解析）

LBA 580061 一带的 TIM2（256x128）

- 内容是行星地图/地形，不是字库

汉字对照（mes_codec.SPECIAL）
- 假名 0–179 另表；SPECIAL 277 个码。catalog 分表合计约 25630 条 jp 已无 {编号} 占位
- 同一编号会撞字（雄/込=469、装/領、開/戻/貢、始/言）。复合词/活用优先；汉化时重占槽
- 图集序号 ≠ 文案码。对照：tools/mes_codec.py；重解：python3 tools/redecode_mes.py（会保留已填 zh）
- 中文：extracted/catalog/*.csv 的 zh 列（python3 tools/apply_zh.py 规范化）
- 专名：extracted/GLOSSARY.txt
- 姓名输入 A–Z 与汉字共槽（N=488 O=305 无汉字可读，已标拉丁）：
  A知 B死 C体 D複 E少 F教 G早 H能 I惑 J分 K守 L小 M中
  N O P力 Q激 R使 S大 T喜 U勢 V誰 W捨 X装 Y備 Z威
  故「アナログコントローラ（DUALSHOCK2）」在 jp 里仍显示为 複勢知小大能O体守2

3. 角色显示名

   - 开局默认将军名：ELF VA `0x41B1A0` 步长 0x80（`inst_elf_cocott` 可可特等，随 `patch_iso.py` 重编码）
   - 英雄／顾问和王国名在 VFS 槽 0 的加密子文件里，译文在 `extracted/catalog/instance.csv`
     （`inst_hero_seva`、`inst_planet_sun`）。`patch_iso.py` 解密后按 catalog zh 重编码。
     子文件 5：7×84 字节英雄表，包装名在 +24。
     子文件 9：518×42 字节据点表，标题在 +20（假名＋旧「星」码 `9497`）。

     `eg_cl_eggm_at1` 等。`patch_iso.py` 随槽 0 一起重编码。
   - 杀手锏显示名不走 mes，在 VFS 槽 0 子文件 12（24×38，名+6，`inst_okunote_000`）。
4. 系统英文（NODATA / DUALSHOCK2 / HOT / OK / DEFCON）不要沿用日文汉字槽的字形
